# Coofix Syria — all project files

| Folder | What |
|---|---|
| `/` (repo root) | Customer store app (Flutter, Android + iPhone) |
| `extras/staff_app/` | Maintenance staff app (Flutter, Android) |
| `extras/wordpress-plugin/` | WordPress plugin "coofix-app" (app control panel, repairs system, staff accounts, website skin) |

Builds (APK / IPA / plugin zip) are attached to the GitHub Releases of this repo.
iPhone IPA is built automatically by GitHub Actions on every push to `main` (branch `builds`).
