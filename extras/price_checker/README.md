# كاشف الأسعار — كوفيكس

تطبيق Android (موبايل وتاب) لكشف أسعار المنتجات بالباركود. يعمل بالكامل على الجهاز ولا يحتاج إلى سيرفر.

- **شاشة البداية:** زرّان، «كاشف الأسعار» و«لوحة التحكم». لوحة التحكم لا تفتح إلا باسم المستخدم وكلمة المرور.
- **كاشف الأسعار:** يعمل بملء الشاشة. الزبون يضغط «اكشف السعر» فتفتح الكاميرا، وعند قراءة الباركود يُسمع صوت القارئ ويظهر الاسم والسعر بخط كبير. بعد 20 ثانية تعود الشاشة للرئيسية، وتبقى الكاميرا مطفأة بين الكشوفات.
- **لوحة التحكم:** رفع ملف CSV أو Excel، إدارة المنتجات، الإحصائيات، الإعدادات، النسخ الاحتياطي، وتغيير الحساب.

## ترتيب أعمدة ملف المنتجات
| عمود 1 | عمود 2 | عمود 3 |
|---|---|---|
| الاسم | السعر بالدولار | الباركود |

انظر الملف `sample-products.csv`. يُتجاهَل سطر العناوين تلقائياً، وتُقبل الفاصلة كفاصل آلاف والنقطة للسنتات.

## الدخول الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `admin`

يمكن تغييرهما من داخل التطبيق (الحساب)، أو تعديل القيمة الافتراضية في `lib/data.dart` (`adminUser` / `adminPass`).

## البناء
```
flutter pub get
flutter build apk --release
```

## الملفات
- `lib/kiosk.dart`: شاشة البداية، شاشة الزبون، الكاميرا، عرض السعر
- `lib/admin.dart`: لوحة التحكم
- `lib/data.dart`: الإعدادات، المنتجات، قراءة CSV وExcel، الإحصائيات
- `lib/theme.dart`: الألوان والخطوط
